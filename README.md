# Anjoy NAVI リニューアル

公開予定ドメイン: https://anjo.sunsun.live/

旧サイト `anjoy-navi.com` の掲載内容を、検索しやすい現代的な地域商業案内として再構成するプロジェクトです。

## 情報の扱い

- 旧サイトに表示されている2,806店は、現在営業中の店舗数として扱いません。
- 店名・住所・電話番号は、公式サイト、安城商工会議所、自治体、事業者の現在発信などと照合します。
- 確認済み、名称変更、要確認を区別し、確認日と情報元を表示します。
- 現在の存在を確認できない事業者は公開データに含めません。

## 初期版

`dist/` に、スマートフォン対応の静的サイトがあります。店名・業種・町名検索、業種フィルター、確認状態表示に対応しています。
